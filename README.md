# EIGRP Routing Lab

## 📌 Overview
This project demonstrates the configuration of the Enhanced Interior Gateway Routing Protocol (EIGRP) using Cisco Packet Tracer.

## 🎯 Objectives
- Configure EIGRP between multiple routers.
- Establish neighbor relationships.
- Verify routing tables.
- Test end-to-end connectivity using ping.

## 🛠️ Tools Used
- Cisco Packet Tracer
- Git
- GitHub

## 🌐 Network Topology
- 3 Routers
- 2 PCs
- Serial Connections
